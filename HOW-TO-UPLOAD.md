# How to put SparkKeys files here

This repo is https://github.com/Vegemite89/Sparkkeys

On an iPhone the GitHub app often hides Upload. Do this in Safari instead:

1. Open this repository.
2. Tap the Aa / share icon → Request Desktop Website.
3. The desktop page shows Add file → Upload files near the green Code button.
4. Upload index.html, preview.html, css/app.css, js/app.js, js/grand-engine.js.

Or use a computer and drag those files onto Upload files.
